## Aim
To measure the period and frequency of a square-wave signal generated by an external function generator using Arduino Uno.

## Problem Statement
Measure the period and frequency of an external square-wave signal using Arduino Uno and display the results on the Serial Monitor.

## Apparatus
- Arduino Uno (ATmega328P)
- Function generator with square-wave or TTL/CMOS output
- 1 kΩ series resistor (recommended for input protection)
- BNC-to-jumper / test leads
- Computer with Arduino IDE 2.x and Serial Monitor
- USB-A to USB-B cable
- Oscilloscope (optional, to verify generator amplitude and frequency)

## Theory
The period T of a periodic signal is the time required for one complete cycle. Frequency f is the number of cycles occurring in one second. They are related by:

- f = 1 / T
- If T is measured in microseconds: f (Hz) = 1,000,000 / T (µs)

For a square wave, one complete cycle consists of a HIGH duration and a LOW duration. Arduino's `pulseIn(signalPin, HIGH)` measures the HIGH duration, while `pulseIn(signalPin, LOW)` measures the LOW duration. Both are returned in microseconds.

The total period is calculated as `period = highTime + lowTime`. The frequency is calculated as `frequency = 1000000.0 / period`.

## Connections

| Function generator | Arduino Uno | Remark |
|---|---|---|

## Program
Open `Measure_Period_Frequency.ino` in Arduino IDE. The program measures HIGH and LOW pulse widths using `pulseIn()`, adds them to obtain the period, calculates frequency, and prints both values at 9600 baud.

## Procedure
1. Keep Arduino disconnected while making the signal connections.
2. Connect the function-generator ground to Arduino GND.
3. Connect the function-generator signal output to Arduino D2 through a 1 kΩ series resistor.
4. Set the function generator to a square wave. Prefer a TTL/CMOS output of approximately 0 V to 5 V. If the main output is used, verify with an oscilloscope that the waveform never goes below 0 V or above 5 V.
5. Connect Arduino Uno to the computer using the USB cable.
6. Open Arduino IDE, select Arduino Uno and the correct COM port.
7. Verify and upload `Measure_Period_Frequency.ino`.
8. Open Serial Monitor and set the baud rate to 9600.
9. Set the function generator initially to 100 Hz. Observe the period and frequency displayed on Serial Monitor.
10. Repeat for 500 Hz, 1 kHz, 2 kHz and 5 kHz, or the values specified by the instructor.
11. Record generator frequency, theoretical period, measured period and measured frequency.
12. Calculate percentage error if required: Error (%) = |Measured frequency − Set frequency| / Set frequency × 100.

## Precautions
- Always connect the function-generator ground to Arduino GND.
- Keep the Arduino D2 voltage between 0 V and 5 V.
- Do not apply a negative-going bipolar waveform directly to D2.
- Use a square wave or TTL/CMOS output; condition a sine wave with a comparator or Schmitt trigger before direct digital measurement.
- Verify signal amplitude before connection whenever generator settings are uncertain.
- Do not make or remove signal connections while high voltage is present at the generator output.

## Conclusion
The period and frequency of an external square-wave signal are measured using Arduino Uno. The `pulseIn()` function measures the HIGH and LOW pulse durations on digital pin 2, and their sum is used to calculate the signal period and frequency.
