# Practical 01
## Arduino and ESP32 Development Environment

### Aim
To set up and test Arduino IDE for programming Arduino Uno and ESP32 boards.

### Requirements
- Computer
- Arduino IDE 2.x
- Arduino Uno
- ESP32 DevKit
- USB cable
- Internet connection

### Programs
1. Arduino Uno Blink
2. ESP32 Blink

### Conclusion
The development environment is configured for Arduino Uno and ESP32.
